## ⭐ 一、核心代码(工具本身,根目录)

| 路径 | 作用 |
|---|---|
| `main.py` | 命令行入口 `python main.py inspect-sop / calculate-sop / make-template` |
| `nutrition_tool/` | 计算核心包,与Excel/网页无关的纯计算 |
| ├ `calculator.py` | **营养计算公式**(可食重×每100g营养×保留率,4-9-4能量校验) |
| ├ `sop.py` | SOP Excel解析 → 菜谱 |
├ `repository.py` | 营养库加载/匹配(**v2:重复编码名称消歧,歧义返回None不猜测**) |
├ `models.py` | 数据模型(9项营养字段) |
├ `service.py` | 版本化服务契约(供网站/API集成) |
├ `cli.py` / `exporters.py` / `templates.py` | 命令行/导出/模板生成 |
`tests/` | 28个测试,`python -m pytest -q` |

## 🐍 二、脚本(scripts/,已分类)

### 桌面程序
| 路径 | 作用 |
|---|---|
| `desktop_app/app.py` | **桌面程序主程序**(Flask网页界面:上传SOP→计算→预览→导出;默认端口 8317,被占用/保留段自动 +1 避让,可用 PORT 环境变量覆盖) |
| `desktop_app/templates/index.html` | 前端页面 |
| `nutrition_tool/dish_export.py` | SOP菜谱 → 菜式管理字段导出(推断+8项营养) |
| `营养素计算工具.spec` | PyInstaller 打包配置(Windows EXE + macOS .app) |
| `dist/营养素计算工具/` | **Windows EXE 产物**(整个文件夹拷贝即用) |
| `.github/workflows/build.yml` | **CI 自动构建**: 推 main 即跑测试+打 Win/Mac 包 → 发 GitHub Releases(tag=latest) |
| `docs/桌面程序打包说明.md` | 打包/使用/macOS打包步骤 + 线上下载地址 |

### CFS 官网对接(抓数据用)
| 文件 | 作用 |
|---|---|
| `scripts/cfs_fetch.py` | CFS官网抓取封装:搜索食物、取18项营养详情 |
| `scripts/batch_fetch_cfs.py` | **批量抓取**:SOP食材 → 营养库(清洗/匹配/断点续跑) |
| `scripts/fix_mismatches.py` | 修复错误匹配(生粉→玉米澱粉、大米→白米等) |
| `scripts/fix_cauliflower.py` | 修复椰菜花被错映射为椰菜 |
| `scripts/refetch_nutrients.py` | 重抓详情,补齐钠/糖/膳食纤维 |
| `scripts/fix_cfc_carbs.py` | **CFC碳水口径修复**:总碳水→可利用碳水(换算+联网补纤维) |
| `scripts/fix_cfc_carbs_round2.py` | 同上第二轮:纯物质/兄弟行补纤维,输出待人工清单 |
| `scripts/fix_cfc_carbs_round3.py` | 同上第三轮:能量按官方4-9-4重算(CFC标签能量按总碳水) |

### 分析与对比
| 文件 | 作用 |
|---|---|
| `scripts/parse_history.py` | 解析4/5/6月历史营养结果 → data/history_results.json |
| `scripts/compare_history.py` | 营养库计算SOP菜品 vs 历史结果比对 |
| `scripts/plan_ab_compare.py` | 方案A/B对比计算 → 报告 |
| `scripts/parse_usda_retention.py` | 解析USDA保留因子表 → data/usda_retention.json |
| `scripts/calc_yield_factors.py` | 用CFS生/熟食材对反推熟重得率 → data/yield_factors.json |
| `scripts/convert_dish_sop.py` | **格式转换**:「菜品SOP」(一行一道菜+配方文本) → 标准「配料sop」工作簿(核心解析器零改动) |
| `scripts/gen_mock_sop.py` | **拟真测试数据生成**:用营养库真实食材生成 5月A-E餐 标准SOP(33菜/226配料行) |
| `scripts/fill_cfc_fibre_cross_source.py` | CFC 待补纤维 16/17 行从 CFS 替代来源补录+重算能量(幂等, 可追溯 progress) |
| `scripts/verify_sep_overlap.py` | 9月菜单×5/6月SOP 重叠菜式验证计算 → 状态/未匹配/警告汇总 + 导出 Excel |
| `scripts/fetch_missing_sep.py` | 9月重叠未匹配食材 CFS 定向抓取(粤语关键词链+近似判定) |
| `scripts/merge_fetched_missing.py` | 抓取结果合并入库(鲜品覆盖+provenance) |
| `scripts/audit_cfs_precise.py` | **官网核对工具**:按 CFS 精确条目名拉详情, 与库值逐字段比对(审计用) |
| `scripts/fix_audit_issues.py` | **审计修复**:10 种匹配错误换正确 CFS 条目(鮮冬菇/蘑菇/蒜蓉/雪菜/芝士腸/黃雪耳/紹菜/雞蛋/菠蘿) |
| `scripts/fix_audit_issues_r2.py` | **审计修复R2**:CFC 碳水未换算 7 行换算+能量重算(鮮菇粉/黑松露/合掌瓜/京蔥/什豆) |

> 日常**不需要运行**这些脚本,营养库已抓好。只有更新/补抓食材时才用。

## 🧭 快速上手:现在该看什么

1. **想了解项目全貌** → `docs/菜单SOP盘点.md` → `docs/cfs_integration.md`
2. **想看计算结果** → `docs/plan_ab_comparison.md`
3. **想补食材数据** → `data/待人工处理食材清单.csv`(128个未匹配,已标注建议)
4. **想跑计算** → 按 `docs/README.md` 命令(数据在 data/ 下)

## 🗂️ 数据流转

```
菜单+SOP/*.xlsx (原始输入)
    ↓ scripts/parse (nutrition_tool/sop.py)
data/ingredients_may|june.csv (唯一食材)
    ↓ scripts/batch_fetch_cfs.py (CFS官网抓取)
data/cfs_progress.json + data/ingredient_nutrients.csv (营养库)
    ↓ scripts/plan_ab_compare.py (计算)
data/planA|B_results.json → docs/plan_ab_comparison.md (对比报告)
```
