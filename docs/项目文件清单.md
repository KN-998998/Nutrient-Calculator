# 项目文件清单

> 更新日期：2026-10-16

## 运行主链路

部署目标为阿里云 ECS 网页服务，不提供或构建 Windows/macOS 桌面可执行程序。

```text
上传 SOP Excel
  → nutrition_tool/sop.py 识别可见的 A–E 主配料页并读取小学/中学克重
  → nutrition_tool/calculator.py + repository.py 计算八项营养
  → web_app/app.py 提供预览、编辑与导出接口
  → nutrition_tool/dish_export.py 使用 data/templates 中的圣类斯模板生成上架表
```

## 代码

| 路径 | 职责 |
|---|---|
| `nutrition_tool/calculator.py` | 独立营养计算、完整性与能量校验 |
| `nutrition_tool/models.py` | 食材、配方、计算结果等领域对象 |
| `nutrition_tool/repository.py` | 营养数据加载、编码/名称/别名匹配 |
| `nutrition_tool/sop.py` | 解析 SOP，忽略隐藏参考页和非主配料页 |
| `nutrition_tool/dish_export.py` | 转换营养结果并按上架模板导出 |
| `nutrition_tool/service.py` | 版本化计算服务契约 |
| `nutrition_tool/history.py` | SQLite 已确认营养值历史记录 |
| `nutrition_tool/cli.py`, `main.py` | 本地检查、食材模板生成及 JSON/CSV 计算入口 |
| `web_app/app.py` | Flask 上传、复核、重算、导出 API |
| `web_app/templates/index.html` | 营养师复核界面 |
| `wsgi.py` | Gunicorn/ECS 入口 |

## 运行数据

| 路径 | 用途 |
|---|---|
| `data/ingredient_nutrients.csv` | 主营养数据库，每 100g 可食部数据及来源 |
| `data/ingredient_nutrient_corrections.csv` | SOP 名称级营养值修订、缺项来源说明及身份未确认拦截；匹配优先于主库 |
| `data/portion_estimates.json` | SOP 缺克重时按明确件数暂估单重的版本化规则 |
| `data/ingredient_nutrients_cfc_fallback.csv` | 香港 CFC 后备食材数据 |
| `data/sop_alias_mapping.csv` | SOP 食材名称与营养记录之间的别名映射 |
| `data/yield_factors.json` | 熟重得率因子 |
| `data/usda_retention.json` | USDA 营养保留因子 |
| `data/templates/聖類斯上架模版.xlsx` | 已移除示例商品行的 15 列上架模板；导出时作为格式来源 |
| `data/cfs_progress.json`, `data/cfs_unmatched.json` | CFS 抓取进度和待复核记录 |

2026 年 9 月营养师复核工作簿已逐项对齐 291 个 SOP 食材名：232 项营养值进入名称级修订档案（166 项八项完整、66 项存在未报告字段），59 项身份/规格未确认记录设置为 `block`。修订数据保留来源、URL、核查日期及适用说明；缺失字段保持空白，继续按计算规则标记复核。

## 文档与维护脚本

- `docs/README.md`：安装、网页运行、输入输出及部署方式。
- `docs/calculation_rules.md`：暂计缺失营养项、按件估重、替代数据及菜品状态规则。
- `docs/ARCHITECTURE.md`：计算核心、Web 适配层和数据边界。
- `docs/香港标准符合性审计.md`、`docs/cfs_integration.md`：营养口径、来源与数据审计记录。
- `scripts/`：CFS 抓取、数据审计、营养库修订与 SOP 格式转换工具；只在维护数据库时使用。

## 清理边界

4、5、6 月原始 SOP/营养工作簿、旧食材清单和测试专用文件已从当前工作目录清理。营养数据库、来源审计文档及 CFS 数据仍保留，因为当前计算和食材匹配依赖它们。`data/history_results.json`、`planA_results.json`、`planB_results.json` 等历史汇总资料暂时保留。
