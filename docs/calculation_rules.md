# 暫行營養計算規則

規則版本：`nutrition.rules.v1`
服務契約：`nutrition.calculation.v3`

本規則用於先產生可供營養師復核的暫算結果。標示為「已計算」或匯出成功，不代表營養師已確認，也不代表所用品牌、規格或估重已與實際採購品完全一致。

## 1. 計算口徑

- 按 SOP 的小學／中學人均用量分開計算；有克重時以該克重為準。
- 單項營養 = 克重 × 可食率 ÷ 100 × 每 100g 營養值 × 營養保留率。
- 可食率、熟重得率及營養保留率沿用營養資料中的明確值，未確認時維持 1.0。
- 一份菜的八項營養值為各食材逐項加總；內部保留精度，輸出時再按格式四捨五入。
- 水按零營養值計算。其他食材只有在來源明確顯示為零時才視為已確認零值。

## 2. 未報告營養項

來源中的空白、`NA`、`ND`、`Trace` 不代表已測得零值。為按現有資料先計算，未報告的八項營養值暫按 0 參與菜品合計，並在逐項資料中保留 `missing_nutrients`，菜品狀態標記為 `review`，提示「暫按0」及需對齊的欄位。

這些暫算值可供內部比較和營養師復核。拿到營養師確認值或實際採購品的 1+7 標籤後，更新對應食材資料並重新計算；不可把暫計 0 當成標籤／檢測結果。

## 3. 克重估算

只有 SOP 克重是 0、空白無法解析或 `#VALUE!`，且能從食材名、菜式明細或緊鄰克重欄的數量欄讀到明確件數時，才按 `data/portion_estimates.json` 中的單重估算。成功估算的克重會標記在食材貢獻和復核提示中。

| 食材 | 暫估單重 |
|---|---:|
| 魚蓉燒賣 | 30g/個 |
| 滷水蛋（熟） | 50g/個 |
| 菜肉水餃 | 25g/隻 |
| 披薩 | 120g/個 |
| 麵包胚 | 45g/個 |
| 車厘茄 | 15g/個 |
| 法蘭克福腸 | 50g/條 |
| 麥樂雞 | 20g/塊 |
| 蜜糖雞尾腸 | 18.9g/條，按同款三條合計56.7g反推 |
| 健康飯卷 | 120g/個 |

另有一項菜式專用處理：北角「洋蔥叉燒炒蛋飯」洋蔥 SOP 克重為 0 時，暫按 42.5g/份估算，依據是相似主菜 1.5oz 洋蔥絲用量。此規則只套用於指定菜式和洋蔥食材。

若克重無效但沒有明確件數，或食材／單位不在估算表內，保留解析警告，不按菜名猜克重。SOP 已有有效克重時，不套用單件估重；例如有實際克重的蝦棗直接用 SOP 數值。

## 4. 食材營養值來源與替代

匹配與取值優先採用香港 CFS／FRL 可確認的相同食材及相同生熟狀態；其次使用實際品牌標籤／規格，再用中國、USDA 或其他可追溯成分資料。找不到完全相同食材時可暫用最接近且可解釋的同類食材，資料必須保留來源、形態和替代原因，狀態為 `review`。

例子包括：不同部位牛肉暫用瘦牛肉熟值；雞球／雞絲等暫用熟雞肉值；瀨粉或米線暫用熟米粉值；不同形狀意粉暫用煮熟白麵粉意粉值。此類替代可先參與計算，拿到專項資料後再替換。

品牌複合食品的通用值或其他品牌標籤不得描述成實際採購品的 1+7 標籤。來源欄要保留品牌、商品名、標示單位和換算方式；若使用同類品牌或通用平均值，清楚標記為暫用參考。

## 5. 菜品狀態及匯出

- `passed`：食材均匹配，沒有估算或其他復核提示。
- `review`：八項結果已按當前資料計算，但有估重、營養缺項暫按 0、替代來源、非香港來源或營養組成校驗提示。暫算值保留並可匯出，需查看逐行提示。
- `incomplete`：存在未匹配食材或 SOP 解析缺項。菜品八項合計可能不完整，不匯出為完整營養值；先處理缺項再計算。

`review` 和 `incomplete` 的暫算結果不會因為匯出而自動寫入已確認歷史；先更新營養檔案或由營養師核實，再進入正式確認流程。

服務回應同時提供契約版本與計算規則版本。修改回應結構或計算狀態語義時，更新契約版本；修改核心公式或暫行規則時，更新規則版本。
