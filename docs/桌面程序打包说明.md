## 产物位置

- **Windows EXE**: `dist/营养素计算工具/营养素计算工具.exe`
  (整个 `dist/营养素计算工具/` 文件夹一起拷贝, 双击 exe 即用, 无需安装 Python)
- **macOS .app**: 需要在 Mac 上打包(见下)
- **线上发布**: GitHub Releases 自动构建, 下载 https://github.com/KN-998998/Nutrient-Calculator/releases/latest
  - `nutrient-calculator-windows.zip` — Windows 版(解压后双击 exe)
  - `nutrient-calculator-macos.zip` — macOS 版(解压后右键打开 .app)

## 自动构建(GitHub Actions, 推荐)

推到 `main` 分支即自动: 跑测试 → 打 Windows exe → 打 macOS .app → 发布到 GitHub Releases(tag=latest 固定覆盖)。

```bash
git push origin main     # 等几分钟, 到 Releases 页拿最新包
```

无需本地安装 Python/PyInstaller。CI 配置在 `.github/workflows/build.yml`。

## 程序功能

- 输入: 一份或多份 SOP Excel(.xlsx, 支持 5月/6月那种「X月X餐配料sop」多sheet格式)
- 输出: 符合 TT 菜單系統「菜式管理」字段的 Excel:
  菜式編號 | SET | 餐名 | 主菜 | 主食材類別 | 具體主食材 | 主食/穀物 | 配菜(蔬菜) | 小食 |
  醬汁/風味 | 烹調方式 | 能量/蛋白質/總脂肪/飽和脂肪/反式脂肪/碳水化合物/糖/鈉 |
  成本 | 圖片網址 | 常規菜單 | 過敏源
- 自动推断: SET(来自sheet名)、烹調方式(菜名)、主食材類別/主食/配菜(食材+菜名)
  → 营养师在系统中可改
- 营养计算: 内置营养库(香港食安中心数据, 267食材), 每100g可食部 × SOP克重, 4-9-4能量校验
- 未匹配食材的菜: 标注状态, 导出后人工复核

## 开发运行

```bash
pip install -r requirements.txt flask
python desktop_app/app.py     # 自动打开浏览器 http://127.0.0.1:8317
# 端口可覆盖: PORT=9527 python desktop_app/app.py
```

## 重新打包(Windows)

```bash
pip install pyinstaller
python -m PyInstaller 营养素计算工具.spec --noconfirm
# 产物: dist/营养素计算工具/
```

## 打包 macOS .app

PyInstaller 不能跨平台打包, 需在一台 Mac 上执行:

```bash
# 1. 拷贝整个项目到 Mac
# 2. 安装 Python 3.11 (https://python.org) + 依赖
python3 -m pip install -r requirements.txt flask pyinstaller

# 3. 打包(spec 已含 BUNDLE 段, 自动生成 .app)
python3 -m PyInstaller 营养素计算工具.spec --noconfirm

# 4. 产物: dist/营养素计算工具.app
```

注意:
- macOS 上首次打开会提示"无法验证开发者"——右键 → 打开 即可(未签名)
- 正式分发建议 Apple Developer 签名 + 公证; Windows 建议代码签名证书
- 当前是 Python 3.11(与打包机一致即可)

## 与 TT 菜單系統的衔接

1. 工具导出 Excel(菜式管理格式)
2. 系统「菜式管理 → 匯入 Excel / 匯入更新」导入
3. 营养师在系统「菜式管理 / 站點菜單檢視及微調」编辑
4. 数据沉淀为系统菜式库历史数据

## 当前限制(第一版)

- 主食材類別/主食/配菜为自动推断(通用名"肉片"按猪肉处理), 需营养师在系统复核
- 营养库 267 食材, 未覆盖的食材标 incomplete, 需人工补
- 烹调方式/酱汁风味为关键词推断, 部分菜可能不准
